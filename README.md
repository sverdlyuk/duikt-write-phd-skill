# duikt write phd skill
Цей скіл — короткий практичний посібник для написання PhD-дисертації у ДУІКТ, складений на основі аналізу шести реальних захищених робіт 2026 року. Пояснює, що має бути в кожному розділі дисертації, як сформулювати мету, завдання й пункти наукової новизни, як оформити методику експерименту та подати результати. 

Дає конкретні орієнтири обсягу (сторінки, рисунки, таблиці), приклади формулювань для анотації й висновків, поради щодо візуалізації і оформлення, а також типовий чекліст перед поданням. Наводить практичні лайфхаки: в яку черговість писати розділи, як підготувати акт впровадження, які статистичні тести використовувати і як робити відтворювані експерименти. Корисно для здобувачів, наукових керівників і рецензентів; можу адаптувати текст під конкретну спеціальність або одразу додати README.md у репозиторій.
